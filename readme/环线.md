### 环线

从 `3.1.3` 版本开始，`环线` 作为实验性功能加入 `Announcer`。

#### 定义
`环线` 在 `Announcer` 中的定义是 `起点站` 和 `终点站` 相同的 `路线`。

相较于非环线路线，`环线`一般只需要添加 `上行` 站点，`下行` 则无需添加。

#### 添加环线

目前，添加路线的两种方式都支持添加`环线`。

通过站点ID添加：只需勾选`是否为环线`即可。

通过地图添加：在提交路线时，选择 `添加为环线，不需要下行` 即可。


#### 进站逻辑

实际上，对于所有路线，`Announcer` 会先检测后面（未经过）的站点，如果检测不到，才会检测前面（已经过）的站点。

这样对于 `环线` 来说，如果你已经从 `起点站` 出站，并且途径中途站点，最后到达 `终点站` 时，`Announcer` 会匹配 `终点站`，而不是 `起点站`。

另外，如果开启了 `从上行终点站出站时切换下行` ，运行 `环线` 时，会直接从 `上行` 的起点站出站，而不会切换到 `下行`。
